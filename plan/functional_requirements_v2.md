## 1. مقدمة ونطاق النظام

### 1.1 الغرض من الوثيقة

تمثل هذه الوثيقة المرجع الرسمي الشامل والمفصل لجميع **المتطلبات الوظيفية** للنظام الموحد الذي يشمل:
- **بنك الأسئلة الإلكتروني المركزي** — لتأليف وإدارة ومراجعة واعتماد الأسئلة.
- **نظام توليد الاختبارات** — لسحب الأسئلة آلياً وبناء ورقة الامتحان وطباعتها.
- **نظام التصحيح الآلي (OMR)** — لمسح أوراق الإجابة ضوئياً واستخراج النتائج.
- **نظام التقارير والإحصاءات** — لتحليل جودة الأسئلة والاختبارات والأداء الأكاديمي.

### 1.2 فئات المستخدمين (User Roles)

| الدور | الوصف |
|-------|-------|
| **مدير النظام (System Admin)** | تهيئة النظام، إدارة المستخدمين والصلاحيات، المزامنة مع البوابة، سجل التدقيق |
| **مؤلف الأسئلة (Author)** | إنشاء الأسئلة وتعديلها واستيرادها وإرسالها للمراجعة |
| **المراجع الأكاديمي (Reviewer)** | مراجعة الأسئلة واعتمادها أو رفضها مع ملاحظات |
| **رئيس القسم (Dept. Head)** | التصعيد والمراجعة النهائية والاعتماد المؤسسي |
| **مسؤول الاختبارات (Exam Manager)** | بناء جداول المواصفات وتوليد الاختبارات وإدارة النماذج |
| **مسؤول الطباعة (Print Officer)** | طباعة كراسات الأسئلة وأوراق الإجابة ومفاتيح التصحيح |
| **مسؤول المسح الضوئي (OMR Operator)** | رفع صور الأوراق الممسوحة وتشغيل محركات الاستخراج والمراجعة البشرية |
| **الطالب / الممتحن (Examinee)** | (بشكل غير مباشر) يتم تسجيل بياناته وربطها بالاختبار والنتائج |

### 1.3 نطاق التطبيق

يخدم النظام كلاً من المؤسسات التعليمية التالية:
- **المدارس:** (مرحلة، صف، مادة، درس) — المصطلحات المدرسية.
- **الجامعات:** (كلية، قسم، مقرر، محاضرة) — المصطلحات الجامعية.
- يتكيف النظام تلقائياً لعرض المصطلحات حسب نوع المؤسسة المسجل.

```
مسودة ──→ قيد المراجعة ──→ معتمد ──→ مؤرشف
  ↑              │              │
  │              ↓              ↓
  └─── مرفوض ←──┘     إصدار جديد ──→ قيد المراجعة
                              ↓
```

### 15.7 مؤشرات القياس النفسي (Psychometric Feedback Loop)

| الرقم | المتطلب | التفصيل |
|-------|---------|---------|

| FR-RPT-19 | معامل التمييز (Discrimination Index) | يجب أن يحسب النظام معامل التمييز لكل سؤال (مقارنة بين أداء المتفوقين والضعفاء) |
| FR-RPT-20 | معامل الارتباط النقطي (Point-Biserial) | يجب أن يحسب النظام معامل الارتباط بين أداء الطالب على السؤال وأدائه الكلي |

| FR-RPT-22 | التحديث التراكمي | يجب أن تُرحَّل المؤشرات النفسية تراكمياً على مستوى بنك الأسئلة ليراها المؤلف والمراجع |
| FR-RPT-23 | عدد مرات الاستخدام | يجب أن يسجل النظام عدد مرات استخدام كل سؤال في الاختبارات |
| FR-RPT-24 | متوسط زمن الحل | يجب أن يحسب النظام متوسط الزمن الفعلي لحل كل سؤال |

## ملحق (أ): قاموس المصطلحات

| المصطلح | الوصف |
|---------|-------|
| **بنك الأسئلة (Question Bank)** | المستودع المركزي الذي يحتوي على جميع الأسئلة المؤلفة والمعتمدة |
| **مستوى بلوم (Bloom's Taxonomy)** | تصنيف معرفي ذو 6 مستويات: تذكر، فهم، تطبيق، تحليل، تقييم، ابتكار |
| **جدول المواصفات (Table of Specifications)** | مصفوفة تحدد التوزيع النسبي للأسئلة حسب الوحدات ومستويات بلوم |
| **OMR (Optical Mark Recognition)** | نظام التعرف البصري على العلامات لتصحيح أوراق الإجابة آلياً |
| **معامل الصعوبة (P-Value)** | نسبة الطلاب الذين أجابوا إجابة صحيحة (0-1، حيث 0 = صعب جداً، 1 = سهل جداً) |
| **معامل التمييز (Discrimination Index)** | الفرق بين أداء الفئة المتفوقة والفئة الضعيفة على السؤال (-1 إلى +1) |
| **Soft Delete (الحذف الناعم)** | نقل العنصر إلى حالة محذوف مع الاحتفاظ ببياناته في قاعدة البيانات |
| **CLO (Course Learning Outcome)** | مخرج التعلم المرتبط بالمقرر الأكاديمي |
| **ABET / NCAAA** | معايير الاعتماد الأكاديمي الأمريكية والسعودية |
